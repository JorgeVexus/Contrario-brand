# Changelog - 2026-08-11

## Resumen de la Sesión
En esta sesión se realizaron ajustes de diseño en la plantilla de producto individual, corrección de compatibilidad en plantillas JSON de Shopify y la reestructuración de la galería de imágenes del producto como un bloque dinámico reordenable.

## Cambios Detallados

### 1. Remoción de Estilo Brutalista en Botones de Producto
- **`assets/section-main-product.css`**: Se anularon las variables de sombra en bloque (`--shadow-horizontal-offset`, `--shadow-vertical-offset`, etc.) dentro de `.product-form__buttons`. Se removió el pseudo-elemento `:before` y se aplicó `box-shadow: none !important` para los botones "Add to Cart" (`.product-form__submit`) y botones de pago dinámico (`.shopify-payment-button` / "Buy with shop").

### 2. Corrección de Sintaxis JSON en Plantillas Shopify
- **`templates/index.json`**: Se eliminó el bloque de comentarios JS (`/* ... */`) en el encabezado para garantizar cumplimiento estricto con el estándar JSON RFC 8259 y evitar errores en el linter/IDE.
- **`sections/header-group.json`**: Se eliminó el comentario JS de encabezado para mantener la validez estándar del archivo JSON.

### 3. Galería de Imágenes Reordenable como Bloque en Plantilla de Producto
- **`sections/main-product.liquid`**:
  - Se agregó la definición del bloque `media_gallery` ("Media gallery") en el `%schema%`.
  - Se añadió el renderizado adaptativo (`product__media-wrapper--desktop-only` para la columna izquierda en Desktop y `product__media-wrapper--mobile-only` dentro de `product__info-container` para Mobile).
- **`assets/section-main-product.css`**: Se añadieron media queries (`@media screen and (min-width: 750px)` y `@media screen and (max-width: 749px)`) para alternar la visibilidad entre Desktop (2 columnas clásicas) y Mobile (galería debajo de botones de compra).
- **`templates/product.json`**: Se registró el bloque `"media_gallery"` dentro de `main` y se actualizó `block_order` colocándolo justo debajo de `"buy_buttons"` y antes de `"description"`.
